### 2.3 Yanlış Başarı Bildirimi (False-Positive Success) Üretebilecek Yollar

1. **Tam Yetki (`full_access=True`) veya Yazma Görevinde Ajanın `run_command` / Kabuk Komutu Hatasını Yutarak Metin Döndürmesi:**
   - **Dosya/Satır:** `core/codex_runtime.py:474-479, 548-549` ve `core/antigravity_runtime.py:421-426, 532-534`.
   - **Mekanizma:** Hem `CodexRuntime._wait` (`not timed_out and code == 0 and record.get("result")`) hem de `AntigravityRuntime._wait` (`not timed_out and code == 0 and record.get("remote_status") in self.SUCCESS and record["result"] and not record["denied_actions"]`), alt süreç `exit_code == 0` ve boş olmayan bir `result` metni döndürdüğünde çalışmayı `status = "completed"` olarak işaretler. Ajanın içeride çalıştırdığı bir `run_command` / `command_execution` sıfırdan farklı `exit_code` ile başarısız olsa veya hiçbir dosya değiştirmese bile (`files_changed == []`), model yanıt metni ürettiği sürece `AgentChatService` mesajı `status: "completed"` olarak kaydeder (`core/agent_chat.py:1255, 1402`).

2. **Yazma Görevinde (`write=True`) `_watch_writer` Kanıt/Sözdizimi Hatasının Sohbet Balonu Durumunu (`completed`) Değiştirmemesi:**
   - **Dosya/Satır:** `core/agent_chat.py:1247-1259, 1399-1406` ve `core/multi_agent_service.py:136-157`.
   - **Mekanizma:** `_execute_antigravity_bubble` ve `_execute_codex_bubble`, CLI süreci biter bitmez (`status == "completed"`) sohbet balonunu `metadata={"status": "completed"}` olarak günceller (`_publish_run_update`). Oysa `MultiAgentService._watch_writer` (`multi_agent_service.py:139-150`) aynı anda arka planda `changed_workspace_files` ve `verify_changed_python` çalıştırmaktadır. Değişen Python dosyasında sözdizimi hatası (` SyntaxError`) bulunsa veya hiç dosya değişmemiş olsa bile sohbet balonu `status: "completed"` kalmakta; doğrulama sonucu yalnızca sonradan `_enrich_messages` (`agent_chat.py:768-770`) ile `metadata["host_evidence"]["source_validation"]` alanına eklenmektedir.
